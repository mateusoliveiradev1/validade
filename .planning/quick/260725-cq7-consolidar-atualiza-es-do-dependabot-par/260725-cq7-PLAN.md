# Quick Task 260725-cq7

## Goal

Atualizar as GitHub Actions já propostas pelo Dependabot em uma única mudança,
agrupar futuras atualizações desse ecossistema e encerrar as PRs substituídas.

## Tasks

1. Atualizar as versões das actions em `ci.yml` e `codeql.yml`.
2. Configurar um grupo único de GitHub Actions no Dependabot.
3. Executar os gates locais, publicar uma PR e aguardar os checks remotos.
4. Após o merge, fechar as PRs individuais como substituídas.

## Verification

- YAML e configuração do Dependabot permanecem válidos.
- `pnpm check` passa.
- Todos os checks obrigatórios da PR passam antes do merge.
- A fila final não contém PRs individuais de GitHub Actions substituídas.
